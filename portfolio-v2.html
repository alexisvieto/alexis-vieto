How I work

The same four steps on every product

STEP 1

Live the problem

I sit with the people who do the work and find the step that costs them hours.

STEP 2

Design the data and the rules

Tables, roles and security come first. Business rules go into the database, where nobody can skip them.

STEP 3

Build with AI

Claude Code writes much of the code. I set the architecture, review every change and decide what ships.

STEP 4

Test, audit, ship

Automated tests, a security review of each module and a check against real data before every release.

My hand-coding is basic. What I bring is knowing what to build, how to structure it so it holds up, and how to check that it works.
