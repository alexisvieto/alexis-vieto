Client project · confidential

AI automation for a food distributor

Shows: Forward Deployed Engineer · AI Automation · Integration Architect

Problem

A Panamanian distributor of domestic and imported meat took orders by phone and WhatsApp and re-typed them into quotes, inventory and dispatch.

What I did

Mapped the manual process on site, then built the automation on top of it: an AI agent extracts product, quantity, date and place from calls and messages; the system checks stock by cut and origin, quotes with each client's price list, confirms payment and schedules the refrigerated route. A person steps in only when stock is short or the client asks.

Result

80%

fewer work hours in the commercial process. No order is re-typed between WhatsApp and delivery.

How I work

I build in Python, TypeScript and JavaScript with Claude Code. I define the architecture, the data model and the security, and I review and test every delivery.

  1. 01

    Live the problem

    I sit with the people who do the work and find the step that costs them hours. The real process, not the documented one.

  2. 02

    Design the data and the rules

    Tables, roles and security first. Business rules go into the database, where nobody can skip them.

  3. 03

    Build with AI

    Claude Code writes much of the code. I set the architecture, review every change and decide what ships.

  4. 04

    Test, audit, ship

    Automated tests, a security review of each module and a check against real data before every release.
